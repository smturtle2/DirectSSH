DirectSSH 화면 설계서

DirectSSH는 사용자 기기 내부에서 SSH 소켓 연결만 수행하는 독립형 Android SSH 클라이언트입니다. 앱은 HOME 세션 관리자와 SSH 터미널, 두 개의 핵심 화면으로 구성됩니다.

아래 두 목업은 각각 다른 화면을 설명하기 위한 대표 예시입니다.
왼쪽은 HOME 화면, 오른쪽은 SSH 화면입니다.

화면 흐름

  • 앱 시작 시 HOME 세션 리스트를 먼저 보여준다.
  • 연결 버튼을 누르면 active session을 만들고 SSH 화면으로 전환한다.
  • SSH 화면에서 HOME 탭을 누르면 연결 유지/종료 정책을 확인한다.
  • 프로필 추가/수정은 별도 화면이 아니라 bottom sheet 또는 overlay로 처리한다.

백엔드 책임

  • Rust/Tauri command가 SSH 연결, 인증, 재연결, 타임아웃을 관리한다.
  • PTY shell과 xterm.js 사이의 입출력 스트림을 이벤트로 연결한다.
  • 키 파일 import, 암호화 저장, 권한 관리를 앱 샌드박스에서 처리한다.
  • 프론트엔드는 세션 상태와 터미널 스트림만 구독한다.

반응형 동작

  • 세로 스마트폰: HOME은 1열 리스트, SSH는 상단 24px 탭 + 터미널 중심.
  • 가로 스마트폰: SSH는 전체 터미널 + 20px 레일을 우선한다.
  • 태블릿/와이드: SSH 화면은 20px 레일과 터미널을 고정하고 여백을 만들지 않는다.

보안 원칙

  • 직접 SSH 연결만 수행하고 프록시/서버 경유를 사용하지 않는다.
  • 모든 자격 증명은 로컬 vault에 암호화 저장한다.
  • 민감 정보는 메모리 체류를 최소화하고 사용 후 즉시 제거한다.

구현 금지사항

  • HOME과 SSH를 한 화면에 큰 split layout으로 동시에 붙이지 않는다.
  • 첫 화면에 큰 입력 폼을 상시 노출하지 않는다.
  • SSH 화면에서 넓은 세션 패널이 터미널 폭을 침범하지 않는다.
